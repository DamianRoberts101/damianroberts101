# Week 17 - Graphics, Interaction, and Capstone Review

- **Chapter:** `ch17`
- **Tier:** Stretch
- **Focus:** graphics, interaction, capstone planning, course synthesis
- **Checkpoint week:** No

## Learning objectives
- Recognize how earlier Java concepts combine in a larger interactive program.
- Plan a small capstone using objects, control flow, and user-facing output.
- Reflect on growth across the Java 101 sequence.

## Suggested live demos
- `ch17/Drawing.java`
- `ch17/Main.java`
- `ch17/VideoGame.java`
- `ch17/RegularPolygon.java`
- `ch17/Sprite.java`

### Lecture compile/run flow
- Compile the chapter once before class:
  - `./scripts/compile-chapter.ps1 -Chapter ch17`
- Suggested classes to run during class:
  - `./scripts/run-chapter.ps1 -Chapter ch17 -MainClass Main`
  - `./scripts/run-chapter.ps1 -Chapter ch17 -MainClass VideoGame`

## Teaching notes
- Start with the smallest example in the chapter, then move toward the most complete one.
- Connect the demo back to the student starter tasks in `student-work/_template/week17`.
- Leave time for students to predict behavior before you run the program.

## Common mistakes to watch for
- Jumping into capstone code without narrowing scope.
- Choosing too many features for the time available.
- Skipping reflection on prior patterns that can be reused.

## In-class practice
- Review where variables, methods, loops, arrays, and objects appear in a graphics program.
- Draft a capstone feature list with core and stretch items.
- Explain which earlier weeks support the final project.

## Exit ticket
List the minimum viable features for your capstone and name the Java topics each feature uses.

## Homework or lab
Produce a capstone proposal with scope, features, files to create, and a simple test plan.

## Pacing and differentiation
- **Tier:** Stretch
- **Remediation move:** Require a minimum-viable-scope plan before students begin any capstone coding.
- **Stretch move:** Ask students to extend the starter task with one self-chosen feature and explain which Java concept it uses.
