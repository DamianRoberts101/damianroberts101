# Week 06 Student Starter

## This week you will practice
- while loops, for loops, counting patterns, strings
- Working from chapter `ch06` examples without editing the canonical book code
- Turning a small scaffold into a finished exercise

## Starter file
- `src/Week06LoopsStarter.java`

## What to do
- Trace the two provided loops and explain what each one does.
- Change one loop bound or step value and predict the new output before you run it.
- Add one more loop and explain the final value of any accumulator you use.

## Practice extension
- Print counting patterns and multiplication rows.
- Accumulate totals across repeated input or generated data.

## Deliverables
- Your completed `src/Week06LoopsStarter.java`

- Any extra files your instructor asks you to submit
