# Week 12 Student Starter

## This week you will practice
- object collections, cards, search patterns
- Working from chapter `ch12` examples without editing the canonical book code
- Turning a small scaffold into a finished exercise

## Starter file
- `src/Week12SearchStarter.java`

## What to do
- Create an array of item names.
- Write a method that searches for a target name.
- Print whether the target was found.

## Practice extension
- Trace a search through card-like data.
- Write a loop that finds a matching object by one field.

## Deliverables
- Your completed `src/Week12SearchStarter.java`
- A short note describing one bug you fixed or one idea you understood better this week
- Any extra files your instructor asks you to submit

## Success check
- I can explain what the program is supposed to do.
- I ran the file after making changes.
- I can point to one line I changed and explain why.
