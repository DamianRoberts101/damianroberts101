# Week 03 Student Starter

## This week you will practice
- scanner input, user prompts, randomness, formatting
- Working from chapter `ch03` examples without editing the canonical book code
- Turning a small scaffold into a finished exercise

## Starter file
- `src/Week03InputStarter.java`

## What to do
- Ask the user for their name and a whole number.
- Echo the values back in one sentence.
- Add one random number and compare it to the user entry.

## Practice extension
- Run `ScannerBug` and explain the unexpected behavior.
- Extend a number guessing starter with extra prompts.

## Deliverables
- Your completed `src/Week03InputStarter.java`
- A short note describing one bug you fixed or one idea you understood better this week
- Any extra files your instructor asks you to submit
