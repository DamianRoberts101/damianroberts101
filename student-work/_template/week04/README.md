# Week 04 Student Starter

## This week you will practice
- methods, parameters, return values, reuse
- Working from chapter `ch04` examples without editing the canonical book code
- Turning a small scaffold into a finished exercise

## Starter file
- `src/Week04MethodsStarter.java`

## What to do
- Implement the provided greeting method.
- Add a second helper that returns a doubled number.
- Call both helpers from `main`.

## Practice extension
- Refactor repeated print logic into a helper method.
- Write methods that convert seconds to formatted time.

## Deliverables
- Your completed `src/Week04MethodsStarter.java`
- A short note describing one bug you fixed or one idea you understood better this week
- Any extra files your instructor asks you to submit
