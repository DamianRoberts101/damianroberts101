# Week 08 Student Starter

## This week you will practice
- recursive thinking, base cases, self-similar problems
- Working from chapter `ch08` examples without editing the canonical book code
- Turning a small scaffold into a finished exercise

## Starter file
- `src/Week08RecursionStarter.java`

## What to do
- Trace the provided `countdown` method with at least two starting values.
- Change the output so the base case prints a message of your choice.
- Add one more recursive method or extend `countdown` with an extra feature.

## Practice extension
- Trace a simple recursive countdown.
- Match base cases to recursive problem statements.

## Deliverables
- Your completed `src/Week08RecursionStarter.java`
- A short note describing one bug you fixed or one idea you understood better this week
- Any extra files your instructor asks you to submit
