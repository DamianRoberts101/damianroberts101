# Week 10 Student Starter

## This week you will practice
- references, object state, geometry-style examples
- Working from chapter `ch10` examples without editing the canonical book code
- Turning a small scaffold into a finished exercise

## Starter file
- `src/Week10ObjectsStarter.java`

## What to do
- Create and print a `Book` object.
- Call a helper that changes one field.
- Print the object again to observe the updated state.

## Practice extension
- Draw reference diagrams for object assignments.
- Modify a point or rectangle example and predict the result.

## Deliverables
- Your completed `src/Week10ObjectsStarter.java`
- A short note describing one bug you fixed or one idea you understood better this week
- Any extra files your instructor asks you to submit

## Success check
- I can explain what the program is supposed to do.
- I ran the file after making changes.
- I can point to one line I changed and explain why.
