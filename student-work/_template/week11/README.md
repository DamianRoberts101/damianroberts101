# Week 11 Student Starter

## This week you will practice
- class design, constructors, getters/setters, instance methods
- Working from chapter `ch11` examples without editing the canonical book code
- Turning a small scaffold into a finished exercise

## Starter file
- `src/Week11ClassDesignStarter.java`

## What to do
- Finish the constructor assignments.
- Add a `summary` method that returns a short description.
- Create two objects in `main` and print their summaries.

## Practice extension
- Instantiate `Time` objects and call their methods.
- Design a small class with two fields and at least one behavior method.

## Deliverables
- Your completed `src/Week11ClassDesignStarter.java`
- A short note describing one bug you fixed or one idea you understood better this week
- Any extra files your instructor asks you to submit

## Success check
- I can explain what the program is supposed to do.
- I ran the file after making changes.
- I can point to one line I changed and explain why.
