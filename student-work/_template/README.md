# Student Template Workspace

Copy this folder before students begin editing files.

Suggested use:
1. Duplicate the current `weekXX` folder into a student-specific workspace.
2. Leave the provided starter files intact until the student has read the week README.
3. Add teacher-specific submission instructions or grading notes outside the template if needed.

This template is intentionally separate from the book code so student experimentation does not overwrite canonical examples.
