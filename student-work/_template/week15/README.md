# Week 15 Student Starter

- 2D arrays, grids, simulation state, Conway basics
- Working from chapter `ch15` examples without editing the canonical book code
- Turning a small scaffold into a finished exercise

- Fill in the rule description comments.

- Explain why the simulation counts neighbors before mutating cells.

## Deliverables
